# TutorialOverlay

[English](README.md) · **Русский**

Экранный оверлей для пошаговых туториалов в любом приложении Windows. Им управляет ИИ-агент (Claude Code) через
MCP: агент видит интерфейс программы, обводит нужные кнопки прямо поверх неё и ведёт пользователя по шагам, а
оверлей сам замечает, что пользователь сделал, и переходит дальше.

Один exe на C# / .NET 8. Написан с нуля: без NuGet-пакетов и сторонних ассетов. Вся графика (кольца, стрелки,
иконки, галочки) рисуется векторно в коде, текст выводится системным шрифтом Windows.

## Что умеет

- **Отметки поверх любой программы** — кольца, рамки, стрелки, подписи. Они привязаны к элементам интерфейса
  (UI Automation), к тексту на экране (встроенное в Windows распознавание текста) или к кусочку картинки и едут
  вместе с окном и при прокрутке. Клики проходят насквозь в программу.
- **Карточка шага** — «Шаг 2 / 5», текст, чек-лист, кнопки «Назад», «Пропустить», «Готово» и «Помощь».
- **Шаг засчитывается сам**: по клику в цель, по цвету пикселя (ячейка включилась), по открывшемуся окну,
  сочетанию клавиш, перетаскиванию, траектории мыши, прокрутке.
- **Маскот «Шажок»** подходит к цели, показывает на неё и говорит, что сделать.
- **Помощь**: пользователь жмёт «?» или обводит место карандашом — агент получает, где пользователь застрял, и
  отвечает прямо в карточке.
- **Библиотека**: пройденный туториал сохраняется и запускается снова из меню значка в трее, уже без агента.

## Установка

Windows 10 или 11, x64. Больше ничего не нужно: .NET уже внутри exe.

**Claude Code** — скачайте `TutorialOverlay-<версия>-win-x64.zip` со страницы
[Releases](https://github.com/kizrum/tutorial_overlay/releases/latest), распакуйте в любую папку (например,
`C:\Tools\TutorialOverlay`) и один раз подключите для всех проектов:

```
claude mcp add --scope user tutorial-overlay -- "C:\Tools\TutorialOverlay\TutorialOverlay.exe" --stdio
```

Это всё: ни ключа, ни порта. Когда оверлей понадобится агенту, тот сам его запустит (в трее появится значок), и
оверлей останется там, пока вы не закроете его из меню значка. Та же команда есть в меню значка в трее:
**«Скопировать команду для агента»**.

**Другие MCP-клиенты** — это локальный (stdio) сервер: команда `TutorialOverlay.exe` с аргументом `--stdio`.
Клиенты со Streamable HTTP могут подключиться и прямо к запущенному оверлею: см. [Server](docs/server.md).

### Обновление

Закройте TutorialOverlay из меню значка в трее и распакуйте новую версию поверх старой папки. Настройки, ключ и
сохранённые туториалы лежат в `%LOCALAPPDATA%\TutorialOverlay` и не меняются; строка `claude mcp add` тоже
остаётся верной.

## Сборка из исходников

[.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0):

```powershell
dotnet publish -c Release -o publish
claude mcp add --scope user tutorial-overlay -- "$PWD\publish\TutorialOverlay.exe" --stdio
```

`.\release.ps1` собирает zip для релиза; см. [Development](docs/development.md).

## Попробовать

Откройте Claude Code и попросите, например:

- «Покажи в Блокноте, где включается перенос по словам» — агент найдёт пункт меню и обведёт его;
- «Проведи меня по шагам: как в Блокноте поменять шрифт» — появятся карточка шага, отметки и маскот; шаги
  засчитываются по вашим кликам;
- «Сделай туториал по FL Studio: добавить канал в Channel rack и включить в нём шаги» — пример для программы,
  которая рисует интерфейс сама.

В конце туториала карточка предложит сохранить его. Сохранённые туториалы — в меню значка: **«Туториалы»**.

Остановить сервер: пункт **«Закрыть TutorialOverlay»** в меню значка или `TutorialOverlay.exe --stop`.
